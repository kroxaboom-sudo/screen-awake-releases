# Screen Awake 0.1.1-preview

## Русский

- Добавлено безопасное обновление прямо из приложения.
- Автоматическая проверка наличия новой версии при открытии приложения.
- Ручная кнопка «Проверить обновления».
- Скачивание и запуск системного установщика Android из приложения.
- Перед установкой APK проверяется по SHA-256 и по сертификату подписи Screen Awake.
- При необходимости приложение открывает системное разрешение «Установка из этого источника».
- Номер версии в интерфейсе берётся из единого источника сборки.
- Сохранены управление активным экраном из уведомления и работа после сворачивания приложения.
- Проверено параллельно на Android 13, 14, 15 и 16.

## English

- Added secure in-app updates.
- Automatic update check when the app opens.
- Manual “Check for updates” action.
- Downloads updates and opens Android's system installer from the app.
- APK is verified against SHA-256 and the Screen Awake signing certificate before installation.
- Opens Android's “Install unknown apps” permission screen when required.
- Displayed version now comes from the single build version source.
- Existing notification controls and background keep-awake behavior are preserved.
- Tested in parallel on Android 13, 14, 15, and 16.
