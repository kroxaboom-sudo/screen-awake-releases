# Screen Awake 0.1.4-preview

## Русский

- Удалено разрешение `REQUEST_INSTALL_PACKAGES`.
- Screen Awake больше не скачивает и не устанавливает APK самостоятельно.
- Проверка новых версий остаётся внутри приложения.
- При наличии обновления приложение открывает официальную страницу GitHub Release.
- Основной режим, восстановление после перезагрузки и Quick Settings сохранены без изменений.
- Полная матрица Android 13 / 14 / 15 / 16 пройдена.

## English

- Removed the `REQUEST_INSTALL_PACKAGES` permission.
- Screen Awake no longer downloads or installs APK files itself.
- Update checks remain available inside the app.
- When an update is available, the app opens the official GitHub Release page.
- Keep-awake mode, reboot recovery, and Quick Settings control remain unchanged.
- Full Android 13 / 14 / 15 / 16 matrix passed.
