# Screen Awake 0.1.5-preview

## Русский

- Добавлен встроенный экран «Диагностика» для проверки поведения на реальном устройстве без ADB.
- Показываются текущий системный тайм-аут, сохранённый исходный тайм-аут и фактическое состояние режима.
- Сохраняются результат и время последнего восстановления после загрузки Android.
- Сохраняются целевой и фактический тайм-аут последнего восстановления при выключении режима.
- Диагностический отчёт можно скопировать одним нажатием.
- Восстановление исходного тайм-аута теперь дополнительно проверяет, что Android действительно применил сохранённое значение.
- Новых разрешений не добавлено; APK по-прежнему не может устанавливать другие APK.

## English

- Added an in-app Diagnostics screen for real-device verification without ADB.
- Shows current system timeout, saved original timeout, and actual keep-awake state.
- Records the result and time of the latest Android boot recovery.
- Records target and actual values from the latest timeout restoration when the mode is disabled.
- The diagnostic report can be copied with one tap.
- Timeout restoration now verifies that Android actually applied the saved value.
- No new permissions were added; the APK still cannot install other APK files.
