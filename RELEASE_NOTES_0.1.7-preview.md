# Screen Awake 0.1.7-preview

## RU

- Добавлен раздел «Статистика».
- Считаются сеансы, суммарное/среднее/максимальное время работы и статистика за 1/7/30 дней.
- Считается успешность включения, выключения, boot-recovery и возврата системного тайм-аута.
- Видно, как чаще управляют режимом: приложение, уведомление или Quick Settings.
- Добавлены копирование отчёта и полный сброс локальной статистики.
- Добавлена добровольная обезличенная отправка агрегатов в Grouple; по умолчанию выключена.
- Не отправляются список приложений, содержимое телефона, постоянный ID устройства или личные данные.
- Runtime-зависимости и новые Android-разрешения не добавлялись.

## EN

- Added the Statistics screen with 1/7/30-day and lifetime usage aggregates.
- Added reliability metrics for enable/disable, boot recovery and timeout restoration.
- Added control-source breakdown, report copy and local reset.
- Added optional anonymous aggregate sharing with Grouple, disabled by default.
- No app list, phone content, stable device identifier or personal data is uploaded.
- No runtime dependencies or new Android permissions were added.
