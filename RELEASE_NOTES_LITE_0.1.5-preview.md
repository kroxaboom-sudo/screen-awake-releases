# Screen Awake Lite 0.1.5-preview

## Русский

- Исправлена причина «кнопка нажимается, но ничего не происходит» после удаления и повторной установки.
- Если старый Screen Awake оставил системный тайм-аут «Никогда», новая Lite больше не считает это активным режимом.
- При отсутствии «Изменение системных настроек» приложение теперь остаётся на экране и открывает собственную страницу помощи.
- На странице помощи виден статус «Разрешено / Не разрешено» и пошаговый путь для Samsung/Android.
- Системные настройки открываются только по отдельной кнопке пользователя; приложение больше не уводит экран автоматически.
- Тайм-аут «Никогда», если он уже был установлен пользователем/системой, сохраняется как исходное значение.
- Play Protect-совместимый Downloads-updater и отсутствие REQUEST_INSTALL_PACKAGES сохранены.

## English

- Fixed the tap-with-no-action issue after uninstall/reinstall.
- If an older Screen Awake installation left the system timeout at Never, the new Lite build no longer mistakes it for an active Screen Awake session.
- Without Modify system settings access, the app now stays visible and opens its own help screen.
- The help screen shows Allowed / Not allowed status and clear Samsung/Android steps.
- System settings open only after a separate explicit user action; the app no longer leaves the screen automatically.
- An existing Never timeout is preserved as the original system value.
- The Play Protect-friendly Downloads updater and absence of REQUEST_INSTALL_PACKAGES are preserved.
