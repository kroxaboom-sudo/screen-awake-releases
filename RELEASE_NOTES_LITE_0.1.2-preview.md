# Screen Awake Lite 0.1.2-preview

## Русский

- Lite получает тот же безопасный Core обновления без REQUEST_INSTALL_PACKAGES.
- Проверенный APK сохраняется в системные «Загрузки»; браузер для обычного обновления не нужен.
- Добавлены пресеты: до отключения, 15/30/60/120 минут и своё время.
- Добавлен режим работы во время зарядки.
- Добавлена защита по уровню батареи 5/10/15/20%.
- Улучшено постоянное уведомление: таймер/длительность и кнопка «+30 мин».
- Quick Settings использует выбранный пресет.
- Добавлен компактный виджет.
- Добавлен экран «Настройки».
- Lite по-прежнему не содержит Full-only экранов подробной локальной диагностики и статистики, но использует тот же GLOBAL-OBS и те же требования безопасности.

## English

- Lite now uses the same safer update Core without REQUEST_INSTALL_PACKAGES.
- The verified APK is saved to system Downloads; a browser is not required for normal updates.
- Added duration presets: until disabled, 15/30/60/120 minutes and custom duration.
- Added keep-awake-while-charging.
- Added 5/10/15/20% low-battery protection.
- Improved persistent notification with timer/elapsed state and +30 min.
- Quick Settings uses the selected preset.
- Added a compact home-screen widget.
- Added Settings.
- Lite still excludes Full-only detailed local diagnostics/statistics screens while keeping the same GLOBAL-OBS and security requirements.
